# Ledge

Ledge files your downloads into typed folders the moment they land — and keeps
the recent ones one click away in the menu bar, still draggable into whatever
you're working in.

Rule-based organizers file things away and break the habit of grabbing what you
just downloaded. Shelf apps keep it reachable but leave the folder a mess.
Ledge does both.

## Status

In development.

## Requirements

macOS 14.0 or later.
